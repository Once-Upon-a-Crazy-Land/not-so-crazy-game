# Not So Crazy Game

Recovered source project for Blocktopia, a 2D game made with Godot.

## Open the project

1. Install Godot 3.5.1 (standard edition).
2. Clone or download this repository.
3. Import `project.godot` in Godot and let the assets import.
4. Press F5 to run the game.

The main scene is `TitleMenu.tscn`.

## Recovery notes

This project was recovered from the original itch.io browser export using Godot RE Tools. All 12 GDScript files were decompiled and all 65 imported resources were converted without reported conversion failures. Original comments and formatting may be missing. Gameplay has not yet been tested after recovery.

Source scripts, scenes, project settings, images, audio, and fonts are included. Generated import caches and recovery logs are excluded.
